## How I work

**For agent and automation builds:** I lead with architecture, not code. The first deliverable is usually a one-page system brief — recommended stack, what to automate, what to never automate — before any line of code is written.

**For LLM-driven products:** I default to confidence-gated patterns over fully autonomous agents. Hallucinations have a dollar cost in production; the architecture should price that in.

**For accessibility:** Default. Not an afterthought. Every agent I build verbalizes actions and waits for input at every irreversible step.

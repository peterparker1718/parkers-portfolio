# Images

Place your project screenshots, photos, and other images here.

## Naming Convention

Use descriptive, kebab-case names:
- `project-ecommerce-homepage.jpg`
- `about-me-photo.jpg`
- `hero-background.jpg`
- `logo-dark.png`
- `logo-light.png`

## Recommended Formats

- **Photos**: JPG (for smaller file sizes)
- **Graphics/Logos**: PNG (for transparency) or SVG (for scalability)
- **Modern browsers**: WebP (for best compression)
